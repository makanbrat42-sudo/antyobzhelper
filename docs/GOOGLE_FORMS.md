# Google Forms → AntyObzhelp

## Форма

Рекомендуемые вопросы (названия можно поменять в «Google Forms → Настройка полей»):

| Вопрос | Обязателен | Зачем |
|---|---|---|
| Ник | да | ник кандидата |
| ФИО | нет | |
| Ссылка на VK | да | `vk.com/id123` или короткое имя |
| Код подтверждения VK | рекомендуется | код со страницы `https://<домен>/link` — подтверждает, что VK принадлежит кандидату |
| остальные | — | попадают в анкету как есть |

В описании формы дайте ссылку на `https://<домен>/link`: кандидат входит через VK ID и получает код. С кодом заявка считается подтверждённой (`VERIFIED`), и автоотказ по ограничению применяется без ручной проверки.

## Apps Script

1. Откройте форму → ⋮ → **Редактор скриптов**.
2. Вставьте код из [`integrations/google-apps-script/Code.gs`](../integrations/google-apps-script/Code.gs).
3. ⚙ Настройки проекта → **Свойства скрипта**:
   - `AOH_ENDPOINT` = `https://<домен>/api/integrations/google-forms`
   - `AOH_SECRET` = значение `GOOGLE_FORMS_SECRET` с сервера
4. Выберите функцию `setup` → **Выполнить** → выдайте разрешения. Будут созданы триггеры отправки и повтора (каждые 10 минут).

## Защита и надёжность

- Подпись: `X-AOH-Signature = HMAC-SHA256(secret, timestamp + "." + body)`, метка времени не старше 15 минут.
- Идемпотентность: повторная доставка того же ответа (`responseId`) не создаёт вторую заявку.
- Сбои сети / 5xx: ответ ставится в очередь в свойствах скрипта и повторяется до 5 раз.
- Все попытки видны в «Google Forms → История поступления заявок» (обработано / дубликат / отклонено / ошибка).
- `resendAll()` повторно отправляет все ответы формы — обработанные сервер пропустит.

> Интеграция проверена тестами эндпоинта и сквозным тестом с подписанными запросами. С реальной Google-формой не проверялась — нужен ваш аккаунт Google.
